# IDE-Bayesian-Stress-Test
An independent Bayesian MCMC validation and model selection benchmarking engine for Infinite Distance Extrapolation (IDE) configurations over `stim` circuit-level rotated surface code stabilizer noise.

## Core Features
* **Exact LOO-CV Model Comparison Engine**: Native out-of-sample likelihood predictions.
* ** PyMC NUTS Sampling Profiler**: Full handling of geometric path transitions.
* **Robust Circuit Pipeline**: Tied into `stim` and `pymatching` decoders.
